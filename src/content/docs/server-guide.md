本文介绍如何加入社区自建的联机服务器，以及连接过程中的常见问题。

## 连接服务器

在游戏内的服务器浏览器中搜索社区公告发布的房间名，或直接使用下方地址加入：

```
join.monoiar.example:7777
```

- 服务器支持 Fusion Mod，请确保已安装对应插件。
- 高峰期可能排队，请耐心等待。

### 推荐设置

为了保证体验，建议按以下配置：

| 设置项 | 建议值 |
| --- | --- |
| 区域 | 华东 / 华南 |
| 语言 | 简体中文 |
| 延迟阈值 | 低于 `120ms` |

## 常见报错

| 错误信息 | 解决办法 |
| --- | --- |
| `Connection failed` | 检查本地防火墙是否放行 `7777` 端口 |
| `Mod mismatch` | 确认客户端插件与服务器版本一致 |
| `Version mismatch` | 更新游戏与汉化补丁到最新版 |

> 提示：若始终无法连接，请到社区频道反馈，并附上日志截图。
